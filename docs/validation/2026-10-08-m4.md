## Verified behavior

Browser tests use 300,000 generated metadata entries to check GUI responsiveness,
rapid query cancellation and continued query progress while metadata is appended.
They cover Unicode case folding/full paths, true numeric/time sorting, missing
values, stable ties, incremental batches and stale archive generations. A real
duplicate-path archive verifies that filtered/sorted selection extracts the exact
original entry's payload. Full-archive totals remain separate from visible rows.

Desktop tests cover persisted themes and Unicode recents, bounded history,
storage failure/recovery, latest coalesced save revisions, source-prefixed task
identity, actual controller lifecycle, task cancellation and finished-history
cleanup. No settings write or sync runs on the GUI thread.

The twelve drag regression groups cover archive content despite misleading
extensions, ordinary inputs/directories, whole-batch remote URL rejection,
password-required detection, sorted original indices, Unicode and native long
paths, hidden files, safe extraction/link skipping, encrypted entries, cancellation
and shutdown. They also verify native QDrag MIME/source through an injected
executor, nested-event reentry/cancellation, desktop-copy retention, four-root
limits under eight concurrent creators and finite cleanup retries with a real
Windows locked-file diagnostic followed by successful recovery.

The production-QML flow sends actual Qt drag-enter/drop events to its DropArea,
opens the detected archive, uses Ctrl+F and sortable headers, restores the correct
selected duplicate, opens/clears the task center through Ctrl+J, clears search
with Escape, prepares file export through its dialog, copies error details, returns
Home, reopens recents and drops an ordinary file into the populated creation form.
It checks both large and 760×480 windows. A small-window regression also asserts
that the recent-list viewport remains visible, after visual QA found its original
layout could collapse to zero height.

## Boundaries

Explorer/Finder/file-manager acceptance of an outgoing native drag was not
manually exercised. QDrag source/MIME, nested execution and temporary extraction
are covered by tests; this is distinct from a real external desktop copy.
Outgoing roots remain available ten minutes after native drag returns; a copy
that outlasts that grace period is not guaranteed. Sudden process termination can
leave temporary roots. Each export is capped at 16 GiB/two hours and 10,000
top-level file URLs, with at most four owned roots.

Linux GUI/macOS runtime, physical screen-reader use, installer/file associations,
million-entry/100 GB archives and this milestone's sanitizer instrumentation were
not exercised. M3 sanitizer evidence remains historical and does not certify the
new Qt query/persistence/temporary-cleanup workers. Backend/OS calls can still
delay cancellation. Platform integration and broader performance/fuzz hardening
remain the later M5/M6 milestones.

Changes are local and have not been committed or pushed.
